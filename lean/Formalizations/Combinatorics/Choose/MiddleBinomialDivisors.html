Everythinghere comes from Kummer's theorem (`padicValNat_choose`: the `p`-adic valuation of a binomialcoefficient counts the carries of the addition in base `p`). * Theorem 1 of the paper: for every integer `k ≠ 1`, `n + k ∤ C(2n, n)` for infinitely many `n`.* The key inequality (4) in the proof of Theorem 2: for a prime `p ≥ 2k`,  `v_p(n + k) ≤ v_p(C(2n, n))` (for `k = 1` this is the integrality of the Catalan numbers).* The construction behind the first half of Theorem 3, left to the reader in the paper: if `p < q`  are primes with `k < p` and `3p/2 < q < 2p`, then `pq ∣ C(2n, n)` for `n = pq + k`. ## Main results * `MiddleBinomial.infinite_not_dvd_centralBinom`: for k != 1, infinitely many n with n + k not dividing C(2n, n) (Theorem 1)* `MiddleBinomial.padicValNat_add_le`: v_p(n + k) <= v_p(C(2n, n)) for primes p >= 2k (inequality (4))* `MiddleBinomial.mul_dvd_centralBinom`: pq divides C(2n, n) for n = pq + k, k < p, 3p/2 < q < 2p* `MiddleBinomial.sub_dvd_centralBinom_of_primes`: hence n - k divides C(2n, n) for n = pq + k (Theorem 3, first half, for one pair) ## References * C.
