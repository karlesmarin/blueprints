Let `L` be a prime, `G` an additive commutative group, and `f : ℤ → G` an `L`-periodic functionthat is a finite sum of `k` arithmetic-progression indicators,`f n = ∑ i, [n ≡ m i (mod N i)] • c i`. Then `f` is constant on all residues mod `L` except atmost `k` of them. ## Proof sketch * `M := ∏_{i : L ∤ N i} N i` is coprime to `L`; pick `b` with `b·M ≡ 1 (mod L)`.* For `r : ℤ`, `n := b·M·r ≡ r (mod L)`, so `f r = f n`. Terms with `L ∤ N i` are evaluated at a  multiple of `N i`, hence equal the constant `c₀`. So `f r ≠ c₀` forces some `i` with `L ∣ N i`.* Such an `i` determines `r mod L`, so the bad residues inject into `Fin k`. The hypotheses `k < L` and `N i ≥ 1` are not needed. ## Main results * `card_ne_const_le`, `card_ne_const_le_of_lt`.-/ @[expose] public section open Finset namespace DGH.FqLower /-- Core counting
