With thediscrete convolution theorem `𝓕 (tileCount A B) k = Ahat A k * Ahat B k`, proved here from thecharacter sums, tiling is equivalent to `#A * #B = 12` together with `Ahat A k = 0 ∨ Ahat B k = 0`for every `k ≠ 0`. ## Main results * `dft_tileCount`, `dft_const_one`.* `tiles_iff_dft_product`, `tiles_iff_dft`.* `chromatic_aug_tiles`, `chromatic_badtriad_not_tiles`: examples. ## References * E. ring /-- **DFT of the constant `1`.** `𝓕(fun _ => 1) k = if k = 0 then 12 else 0` (`= 12·δ₀`), by    orthogonality of the standard additive character: the full character sum is `12` at `k = 0` and    vanishes for `k ≠ 0` (`Fourier.dft_one_apply_ne`). -/theorem dft_const_one (k : ZMod 12) :    𝓕 (fun _ : ZMod 12 => (1 : ℂ)) k = if k = 0 then (12 : ℂ) else 0 := by  rw [dft_apply]  simp only [smul_eq_mul, mul_one]  by_cases hk : k = 0  · subst hk    simp  · rw [ite_eq_right hk]    exact dft_one_apply_ne hk /-- The constant function `1` and the convolution count have equal DFTs iff `tileCount = 1` pointwise    (`ZMod.dft` is a `LinearEquiv`, hence injective). -/lemma tileCount_eq_one_iff_dft_eq (A B : Finset (ZMod 12)) :    Tiles A B ↔ (fun x => (tileCount A B x : ℂ)) = (fun _ => (1 : ℂ)) := by  unfold Tiles  constructor  · intro h;
