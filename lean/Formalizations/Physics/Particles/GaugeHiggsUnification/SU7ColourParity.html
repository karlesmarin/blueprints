All rights reserved.Released under Apache 2.0 license as described in the file LICENSE.Authors: Carles Marín-/module public import Mathlib.Data.Fintype.Prodpublic import Mathlib.Data.Int.Basic /-!# The `x₆` parity of `SU(7)` gauge components separates colour In the `SU(7)` gauge-Higgs unification model of Komori–Maru the parity acting in `x₆` is`P₆ = diag(+,+,+,−,−,−,−)`: the first three indices of the fundamental are the colour triplet.A gauge component along `E_ij` carries the product `P₆(i) P₆(j)`. This file proves thearithmetic half of the theorem "colour lives on the small circle": `P₆(i) P₆(j) = −1` iff exactlyone of `i, j` is a colour index, and there are exactly `24` such components. The other half (the`P₆`-odd components expand in `sin (m x₆ / R₆)`, `m ≥ 1`) is a reading of the mode expansions ofKomori–Maru and is not formalized. ## Main results * `colourParity_neg_iff`: `P₆ i * P₆ j = −1 ↔ (IsColour i ↔ ¬ IsColour j)`.* `colourChanging_card`: exactly `24` ordered index pairs `(i, j)` have `P₆ i * P₆ j = −1`.* `colourChanging_parity_neg`: no colour-changing component has `P₆ = +1`. ## References * C. Marín, *An Upper Bound on the Compactification Scale of `SU(7)` Grand Gauge-Higgs Unification,  and the Dijet Angular Distribution That Tests It (Part VII)*, Zenodo, doi:10.5281/zenodo.22087252,  eq.
