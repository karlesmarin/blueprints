Thereflection-coset character is `D_λ(t) = s_λ(1, −1, t, 1/t)` and the boundary-condition sign `η`acts by `D ↦ η D`, so `η` is unobservable on `λ` iff `D_λ = 0`. In Dynkin coordinates `(a, b, c)`with `λ = (a+b+c, b+c, c, 0)`, `GaugeHiggsUnification.NotchCentreCharge.notch_degenerate_iff`gives the vanishing criterion `N a b c = 0 ↔ Odd b ∧ ((Odd a ∧ Odd c) ∨ a = c)`. This file writesthat set (the blind set) in partition coordinates and counts it. ## Main results * `Blind`: the blind set as two branches: (a) `l₁` odd, `l₂` even, `l₃` odd; (b) `l₁` odd, `l₂`  odd, `l₃` even with `l₂ + l₃ = l₁`.* `blind_iff_notch`: on `l₁ ≥ l₂ ≥ l₃` this is the Dynkin-coordinate criterion.* `blind_iff_N_zero`: `Blind` holds iff the bialternant determinant `N` vanishes.* `blind_l1_odd`: `l₁` is odd on the whole blind set.* `card_shell`: the blind partitions with `l₁ = 2k+1` number `⌈(k+1)²/2⌉`. The parity of `l₂`  splits them into the two branches: branch (a) is the strict pairs `q < p ≤ k` (a triangular  number, via `Finset.sum_range_id_mul_two`) and branch (b) is the interval `m ≤ k/2`. ## References * C.
