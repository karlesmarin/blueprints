The state is `ψ = exp(−i θ σₓ / 2) |0⟩ = cos(θ/2) |0⟩ − i sin(θ/2) |1⟩`; it depends on the pulse onlythrough the accumulated angle `θ(t) = ∫₀ᵗ f`. Then `⟨σₓ⟩ = 0`, so `ΔE(t) = f(t)/2`,`∫₀ᵀ ΔE = θ(T)/2` and `|⟨ψ(0), ψ(T)⟩| = |cos(θ(T)/2)|`. Scope: the trajectory `ψ(t) = qubitState (∫₀ᵗ f)` is used as the evolution; for continuous `f` weprove (`hasDerivAt_trajectory`) that it solves the Schrödinger equation `ψ′ = −i (f σₓ / 2) ψ`with `ψ(0) = |0⟩` (uniqueness is not proved). The statements without the `Continuous f`hypothesis are about the trajectory only. ## Main results * `QSL.FixedAxis.energyStd_qubitState`: `ΔE = a/2` for `H = (a/2) σₓ` on every `qubitState θ`* `QSL.FixedAxis.arccos_overlap_qubitState`: `arccos ‖⟪ψ(0), ψ(θ)⟫‖ = θ/2` for `0 ≤ θ ≤ π`* `QSL.FixedAxis.mandelstam_tamm_integral_eq`: for `f ≥ 0` with `∫₀ᵀ f ≤ π`,  `∫₀ᵀ ΔE(t) dt = arccos ‖⟪ψ(0), ψ(T)⟫‖`* `QSL.FixedAxis.pi_pulse_quantum_speed_limit_ratio`: for `∫₀ᵀ f = π` the final state is orthogonal  to the initial one and `∫₀ᵀ ΔE = π/2`: the Mandelstam–Tamm ratio is exactly `1`, whatever `f`* `QSL.FixedAxis.arccos_overlap_lt_of_pi_lt`: strict inequality for `π < θ < 3π` ## References * L.
