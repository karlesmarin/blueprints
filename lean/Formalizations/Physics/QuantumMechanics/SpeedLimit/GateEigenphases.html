Exact speed limits from geometry*,arXiv:2604.23031 (2026), eq. (3), state the general bound `T ≥ Δφ⋆ / Ω_max`. This file gives anelementary proof via the shifted Mandelstam–Tamm bound (Duhamel estimate of`QSL.Qudit.fsAngle_exp_add_exp_le` plus the triangle inequality of the Fubini–Study angle), andonly for gaps `Δφ ≤ π`.
