This file checks the algebraic chain of both derivations of thecorrected coefficient, with `L = log N`. The asymptotic statement (`→` as `N → ∞`, which needsEuler–Maclaurin bounds for the harmonic sums) is not formalized. The integral`∫₁ᴺ log x / x dx = (log N)²/2` behind it is `integral_log_div_self`(`Formalizations.Analysis.SpecialFunctions.Integrals.LogDivSelf`). ## Main results * `var_log_d_identity`, `cv_from_cumulant_at_hagedorn` (cumulant route):  `L²/3 − (L/2)² = L²/12`, and `C_V = γ² Var(log d) = L²/12` at `γ = 1`.* `log_one_plus_x_coefficient_24`, `log_z_quadratic_coefficient`, `log_z_to_U_coefficient`  (Taylor route): `1/6 − 1/8 = 1/24`, `2 · L²/24 = L²/12`.* `deriv_U_corrected_at_one`, `cv_corrected_at_hagedorn`: for  `U(γ) = L/2 + (1 − γ) L²/12`, `U'(1) = −L²/12` and `C_V = −γ² U'(1) = L²/12`.* `original_is_three_times_corrected`, `original_ne_corrected`, `cv_factor_three_decomposition`:  the published `L²/4` is three times the corrected value and differs from it for `L ≠ 0`. ## References * C.
