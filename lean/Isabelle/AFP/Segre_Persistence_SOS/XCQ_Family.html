License:    BSD*) (* encaje: the family F_t = Q + t w^2 above the Xu-Cui-Qi form of length eight: 8 squares for t >= 1/2 *)section \<open>A family above the Xu--Cui--Qi form of length eight\<close> theory XCQ_Family  imports Complex_Mainbegin text \<open>Let $Q$ be the $4\times3$ biquadratic form of Xu, Cui and Qi @{cite XCQ} (Theorem 4.1), which is  a sum of eight squares of bilinear forms and of no fewer, and let $w = d + h + l$ with  $d = x_1y_0$, $h = x_2y_1$, $l = x_3y_2$ (indices from $0$). For $t > 0$ the Gram matrix of  $F_t = Q + t\,w^2$ built from its nine forms is an extreme point of rank nine of the Gram  spectrahedron; this was checked by computation and is not formalized here. Nevertheless $F_t$ is a  sum of eight squares for every $t \ge 1/2$, and of seven at $t = 1/2$. This theory proves the  polynomial identity behind it and the resulting representations. The variables are  $x\colon \mathbb{N}\to\mathbb{R}$ and $y\colon \mathbb{N}\to\mathbb{R}$, read on the indices  $0..3$ and $0..2$.\<close> definition xcq_z :: "(nat \<Rightarrow> real) \<Rightarrow> (nat \<Rightarrow> real) \<Rightarrow> nat \<Rightarrow> nat \<Rightarrow> real" where  "xcq_z x y i j = x i * y j" text \<open>The form $Q$ of @{cite XCQ}, Theorem 4.1.\<close> definition xcq_Q :: "(nat \<Rightarrow> real) \<Rightarrow> (nat \<Rightarrow> real) \<Rightarrow> real" where  "xcq_Q x y = (xcq_z x y 0 0)\<^sup>2 + (xcq_z x y 1 1)\<^sup>2 + (xcq_z x y 2 2)\<^sup>2 + (xcq_z x y 0 1)\<^sup>2     + (xcq_z x y 1 2)\<^sup>2 + (xcq_z x y 2 0)\<^sup>2 + (xcq_z x y 3 0)\<^sup>2     + (xcq_z x y 3 1 + xcq_z x y 0 2)\<^sup>2" definition xcq_d :: "(nat \<Rightarrow> real) \<Rightarrow> (nat \<Rightarrow> real) \<Rightarrow> real" where "xcq_d x y = xcq_z x y 1 0"definition xcq_h :: "(nat \<Rightarrow> real) \<Rightarrow> (nat \<Rightarrow> real) \<Rightarrow> real" where "xcq_h x y = xcq_z x y 2 1"definition xcq_l :: "(nat \<Rightarrow> real) \<Rightarrow> (nat \<Rightarrow> real) \<Rightarrow> real" where "xcq_l x y = xcq_z x y 3 2" text \<open>The family $F_t = Q + t\,(d + h + l)^2$.\<close> definition xcq_F :: "(nat \<Rightarrow> real) \<Rightarrow> (nat \<Rightarrow> real) \<Rightarrow> real \<Rightarrow> real" where  "xcq_F x y t = xcq_Q x y + t * (xcq_d x y + xcq_h x y + xcq_l x y)\<^sup>2" text \<open>Six squares.\<close> definition xcq_S :: "(nat \<Rightarrow> real) \<Rightarrow> (nat \<Rightarrow> real) \<Rightarrow> real" where  "xcq_S x y = (xcq_z x y 0 0)\<^sup>2 + (xcq_z x y 0 1)\<^sup>2 + (xcq_z x y 0 2 + xcq_z x y 3 1)\<^sup>2     + (xcq_z x y 2 2)\<^sup>2 + (xcq_z x y 1 1 + xcq_z x y 2 0)\<^sup>2 + (xcq_z x y 1 2 + xcq_z x y 3 0)\<^sup>2" text \<open>The scaled identity, valid for every real $t$.\<close> theorem scaled_identity:  "t * xcq_F x y t = t * xcq_S x y + (t * (xcq_h x y + xcq_l x y) + (t -
