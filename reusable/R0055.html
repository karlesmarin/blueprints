  5. Fetch and check

    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Praeger's theorem on bounded movement: if a group acts on Ω with no fixed point and every finite set moved off itself by some element has at most m ≥ 1 points, then Ω is finite, there are at most 2m − 1 orbits, every orbit has at most 3m points and |Ω| ≤ 3m + t − 1, t the number of orbits.

Lean statement

Lean 4
theorem praeger_bounded_movement {G Ω : Type*} [Group G] [MulAction G Ω] (m : ℕ) (hm : 1 ≤ m)
    (hfix : ∀ x : Ω, ∃ g : G, g • x ≠ x)
    (hmove : ∀ (Γ : Finset Ω) (g : G), (∀ x ∈ Γ, g • x ∉ Γ) → Γ.card ≤ m) :
    Finite Ω ∧ Nat.card (MulAction.orbitRel.Quotient G Ω) ≤ 2 * m - 1 ∧
      (∀ x : Ω, Nat.card (MulAction.orbit G x) ≤ 3 * m) ∧
      Nat.card Ω ≤ 3 * m + Nat.card (MulAction.orbitRel.Quotient G Ω) - 1

Lean docstring

Praeger's theorem on bounded movement. Let a group G act on Ω so that every point is moved by some element, and suppose that whenever g maps a finite set Γ off itself, #Γ ≤ m (with m ≥ 1). Then Ω is finite, there are at most 2m − 1 orbits, every orbit has at most 3m points, and |Ω| ≤ 3m + t − 1, where t is the number of orbits.

  • Archive: Praeger.bounded_movement (Formalizations.GroupTheory.GroupAction.BoundedMovement); the module cites no paper DOI of ours.
  • Classical reference: C. E. Praeger, On permutation groups with bounded movement, J. Algebra 144 (1991) 436–442; R. Whitty, Theorem of the Day, «Praeger's Theorem on Bounded Movement».
  • Example: with m = 1 there is at most one orbit.
