Use this theorem

  1. Create a project

    Shell
    lake +leanprover/lean4:v4.35.0 new myproject std.toml
cd myproject

    Standard template, not math: the math template adds its own Mathlib requirement pinned to the Lean release tag, not to the Mathlib commit this package is built and tested with, so you would get a second, different Mathlib. Mathlib comes in through this package. Skip this step in an existing project with the same Lean and Mathlib.

  2. Add the dependency to lakefile.toml

    TOML
    [[require]]
name = "formalizations"
git = "https://github.com/karlesmarin/formalizations"
rev = "v0.13.0"

  3. Import the minimal module

    Lean 4
    import Formalizations.Reusable.GroupTheory

    In a file of the project, e.g. Example.lean.

  4. Paste the example

    Lean 4
    open Formalizations.Reusable
open Classical in
open scoped Pointwise in

/-- The collineation group of the Fano plane has order 168. -/
example :
    Nat.card (MulAction.stabilizer (Equiv.Perm (Fin 7))
      ({{0, 1, 2}, {0, 3, 4}, {0, 5, 6}, {1, 3, 5}, {1, 4, 6}, {2, 3, 6}, {2, 4, 5}} :
        Finset (Finset (Fin 7)))) = 168 :=
  fanoGroup_card

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableGroupTheoryExample.lean at v0.13.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

The group of permutations of the seven points of the Fano plane that preserve its seven lines has order 168.
