Oscillation of the Airy equation

Every solution f of the Airy equation f'' = x f on ℝ has zeros unbounded below: for every M there is x < M with f x = 0.

example (f f' : ℝ → ℝ) (hf : ∀ x, HasDerivAt f (f' x) x)
    (hf' : ∀ x, HasDerivAt f' (x * f x) x) : ¬ BddBelow {x | f x = 0} := by
  rintro ⟨m, hm⟩
  obtain ⟨x, hx, h0⟩ := airy_eq_zeros_unbounded_below f f' hf hf' m
  exact absurd (hm h0) (not_le.2 hx)

Lean docstring

Oscillation of the Airy equation. If f is differentiable with derivative f', and f' is differentiable with derivative x ↦ x f x (that is, f'' = x f everywhere), then f has a zero below every bound: for every M there is x < M with f x = 0. This holds for every solution, including the zero solution; the proof is a Sturm comparison with sin (√c (x − a)) built from Rolle's theorem and the intermediate value theorem (Mathlib has no Sturm theory).

  • Archive: Airy.sturm_unbounded_zeros (Formalizations.Analysis.SpecialFunctions.Airy.Basic).
  • Paper: C. Marín, How a Falling Particle Counts Its Floors (2026), doi:10.5281/zenodo.20787671.
  • Classical reference: DLMF §9.9 (zeros of the Airy functions); E. A. Coddington, N. Levinson, Theory of Ordinary Differential Equations, ch. 8 (Sturm comparison).
  • Example: for a solution f with hf, hf', airy_eq_zeros_unbounded_below f f' hf hf' 0 gives a negative zero of f.
