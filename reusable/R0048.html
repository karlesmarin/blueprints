  4. Paste the example

open Classical in

/-- Singmaster: the integer `2` occurs at most twice in Pascal's triangle. -/
example : {p : ℕ × ℕ | p.2 ≤ p.1 ∧ Nat.choose p.1 p.2 = 2}.ncard ≤ 2 := by
  have h := (ncard_choose_eq_le_two_mul_log 2 le_rfl).2
  have hl : Nat.log 2 2 = 1 := Nat.log_eq_of_pow_le_of_lt_pow (by norm_num) (by norm_num)
  rw [hl] at h
  simpa using h

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableCombinatoricsExample.lean at v0.14.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Singmaster's bound. An integer a ≥ 2 occurs at most 2 ⌊log₂ a⌋ times in Pascal's triangle: the set of positions (n, k) with k ≤ n and C(n, k) = a is finite with at most that many elements. This is a sharpening of the form stated by Singmaster, 2 + 2 ⌊log₂ a⌋ (archive: Singmaster.ncard_choose_eq_le).
