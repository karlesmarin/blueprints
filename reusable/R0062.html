/-- The kurtosis bound for a Gaussian variance mixture. -/
example (μ : Measure ℝ) [IsProbabilityMeasure μ]
    (h₂ : MemLp (fun v : ℝ => v) 2 μ) (h₀ : ∀ᵐ v ∂μ, 0 ≤ v)
    (hmean : 0 < ∫ v, v ∂μ) :

    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

For independent standard normal Z and nonnegative V with finite second moment and positive mean, √V · Z has kurtosis 3 E[V²] / E[V]² and excess kurtosis 3 Var(V) / E[V]² ≥ 0.

Lean statement

Lean 4
theorem variance_mixture_kurtosis_identity
    (μV : Measure ℝ) [IsProbabilityMeasure μV]
    (hV2 : MemLp (fun v : ℝ => v) 2 μV)
    (hVnn : ∀ᵐ v ∂μV, 0 ≤ v)
    (heV : 0 < ∫ v, v ∂μV) :
    (∫ ω, (Real.sqrt ω.1 * ω.2) ^ 4 ∂(μV.prod (gaussianReal 0 1)))
        / (∫ ω, (Real.sqrt ω.1 * ω.2) ^ 2 ∂(μV.prod (gaussianReal 0 1))) ^ 2
      = 3 * (∫ v, v ^ 2 ∂μV) / (∫ v, v ∂μV) ^ 2
    ∧ (∫ ω, (Real.sqrt ω.1 * ω.2) ^ 4 ∂(μV.prod (gaussianReal 0 1)))
          / (∫ ω, (Real.sqrt ω.1 * ω.2) ^ 2 ∂(μV.prod (gaussianReal 0 1))) ^ 2 - 3
      = 3 * ((∫ v, v ^ 2 ∂μV) - (∫ v, v ∂μV) ^ 2) / (∫ v, v ∂μV) ^ 2
    ∧ 3 ≤ (∫ ω, (Real.sqrt ω.1 * ω.2) ^ 4 ∂(μV.prod (gaussianReal 0 1)))
          / (∫ ω, (Real.sqrt ω.1 * ω.2) ^ 2 ∂(μV.prod (gaussianReal 0 1))) ^ 2

Lean docstring

The kurtosis of √V * Z, for independent nonnegative V and standard normal Z, is 3 E[V²] / E[V]². Its excess kurtosis is 3 Var(V) / E[V]² and is nonnegative. Archive: Superstatistics.variance_mixture_kurtosis_identity'.
