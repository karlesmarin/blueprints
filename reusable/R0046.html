  5. Fetch and check

    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Laplacian factorization. The Gram matrix of the oriented incidence matrix of a finite simple graph on a linearly ordered vertex type is the graph Laplacian: N * Nᵀ = D - A (Mathlib's SimpleGraph.lapMatrix), over any ring. The unoriented incidence matrix gives D + A instead.

  • Archive: SimpleGraph.orientedIncMatrix_mul_transpose (Formalizations.Combinatorics.SimpleGraph.OrientedIncMatrix); the module cites no paper DOI of ours.
  • Classical reference: N. Biggs, Algebraic Graph Theory (2nd ed., 1993), ch. 4; C. Godsil, G. Royle, Algebraic Graph Theory (2001), §8.3 (oriented incidence matrix) and §13.1 (the Laplacian).
  • Example: a graph on Fin 3 over ℤ.

Upstream

Mathlib has the Laplacian and the unoriented incidence matrix but not the oriented one
