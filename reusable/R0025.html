Lean docstring

Diagonal entries of the adjugate are principal minors. For a square matrix A over a commutative ring, indexed by any finite type n, adjugate A i i is the determinant of the principal submatrix obtained by deleting row and column i (indexed by the subtype {j // j ≠ i}). Mathlib has the statement for all entries when n = Fin k.succ (Matrix.adjugate_fin_succ_eq_det_submatrix); this form needs no reindexing. With Jacobi's formula (derivative_det_eq_trace_adjugate_mul) it gives charpoly′ = Σᵢ charpoly (A with row and column i deleted).

  • Archive: Matrix.adjugate_apply_self_eq_det_submatrix (Formalizations.LinearAlgebra.Matrix.Adjugate, a tool for the Ihara trace formula in the same archive); the module cites no paper DOI of ours.
  • Classical reference: textbook (Laplace expansion of the cofactor).
  • Example: for A = !![a, b; c, d], adjugate A 0 0 = d, the 1 × 1 minor left after deleting row and column 0.

Upstream

Mathlib has it only for Fin (n + 1) indices (adjugate_fin_succ_eq_det_submatrix); this is the index-free diagonal case
