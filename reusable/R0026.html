  4. Paste the example

/-- Wolstenholme as a divisibility: `p³ ∣ C(2p, p) − 2` in `ℤ` for every prime `p ≥ 5`. -/
example (p : ℕ) (hp : p.Prime) (h5 : 5 ≤ p) :
    (p : ℤ) ^ 3 ∣ (Nat.choose (2 * p) p : ℤ) - 2 := by
  have h := Nat.modEq_iff_dvd.1 (wolstenholme_choose_modEq p hp h5).2.symm
  push_cast at h
  exact h

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableNumberTheoryExample.lean at v0.3.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Wolstenholme's theorem (1862). For a prime p ≥ 5, C(2p − 1, p − 1) ≡ 1 (mod p³) and, equivalently, C(2p, p) ≡ 2 (mod p³), with Mathlib's Nat.choose and Nat.ModEq. The proof shows that the harmonic sum Σ_{k<p} 1/k vanishes in ZMod (p²) and expands (p − 1)! · C(2p − 1, p − 1) = Π_{k<p} (p + k) in ZMod (p³).

  • Archive: Wolstenholme.choose_modEq (Formalizations.NumberTheory.Wolstenholme); the module cites no paper DOI of ours.
  • Classical reference: J. Wolstenholme, On certain properties of prime numbers, Quart. J. Pure Appl. Math. 5 (1862) 35–39.
  • Example: for p = 5, C(9, 4) = 126 = 1 + 125.
