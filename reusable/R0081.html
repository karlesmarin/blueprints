  1. Create a project

    Shell
    lake +leanprover/lean4:v4.35.0 new myproject std.toml
cd myproject

    Standard template, not math: the math template adds its own Mathlib requirement pinned to the Lean release tag, not to the Mathlib commit this package is built and tested with, so you would get a second, different Mathlib. Mathlib comes in through this package. Skip this step in an existing project with the same Lean and Mathlib.

  2. Add the dependency to lakefile.toml

    TOML

name = "formalizations"
git = "https://github.com/karlesmarin/formalizations"

  3. Import the minimal module

    Lean 4
    import Formalizations.Reusable.Combinatorics

    In a file of the project, e.g. Example.lean.

  4. Paste the example

    Lean 4
    open Formalizations.Reusable Filter Topology Classical

/-- `trace_sub_matchingPoly_root_power_sum_eq_trace_hashimoto` applies at the extended girth
whenever it equals a positive natural number. -/
example {V : Type*} [Fintype V] [DecidableEq V] (G : SimpleGraph V) [DecidableRel G.Adj]
    {k : ℕ} (hk : 0 < k) (hg : (k : ℕ∞) = G.egirth) :
    ((G.adjMatrix ℕ ^ k).trace : ℂ) - ((G.matchingPoly.map (algebraMap ℝ ℂ)).roots.map (· ^ k)).sum
      = (G.hashimoto ℂ ^ k).trace :=
  trace_sub_matchingPoly_root_power_sum_eq_trace_hashimoto G hk (by rw [hg]; exact le_self_add)

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableCombinatoricsExample.lean at v0.15.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Matching gap law. For 1 ≤ k ≤ girth + 1, the adjacency trace minus the k-th power sum of the complex matching roots, counted with multiplicity, equals the Hashimoto trace.

  • Archive: SimpleGraph.trace_sub_matchingPowerSum_eq_trace_hashimoto.
  • Example: the identity applies at the girth of every finite graph that contains a cycle.

Upstream

Connects the archive’s matching polynomial and Hashimoto matrix using Mathlib’s roots and matrix trace.
