/-- `matchingPoly_root_power_sum_eq_pathTree_walks` at order zero counts the trivial walk at each

example {V : Type*} [Fintype V] [DecidableEq V] (G : SimpleGraph V) [DecidableRel G.Adj] :
    ((G.matchingPoly.map (algebraMap ℝ ℂ)).roots.card : ℂ) = Fintype.card V := by

  5. Fetch and check

    Shell

lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Godsil’s moment theorem: the sum of kth powers of the complex matching roots with multiplicity counts closed tree-like walks of length k, expressed by the root entries of the path-tree adjacency matrix powers.

Lean statement

Lean 4
theorem matchingPoly_root_power_sum_eq_pathTree_walks {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] (k : ℕ) :
    ((G.matchingPoly.map (algebraMap ℝ ℂ)).roots.map (· ^ k)).sum =
      ((∑ v : V, ((G.pathTree v).adjMatrix ℕ ^ k) (G.pathTreeRoot v) (G.pathTreeRoot v)) : ℕ)

Lean docstring

Godsil's moment theorem. The sum of the k-th powers of the complex roots of a finite simple graph's matching polynomial, with multiplicity, equals the number of closed tree-like walks of length k. For each starting vertex v, count closed walks from the root of the path tree at v using the root–root entry of the k-th power of its adjacency matrix.

  • Archive: SimpleGraph.matchingPowerSum_eq_treeLikeWalkCount and SimpleGraph.treeLikeWalkCount_eq_sum_pathTree_adjMatrix_pow.
  • Classical reference: C. D. Godsil, Matchings and walks in graphs, J. Graph Theory 5 (1981) 285–297.
  • Example: at k = 0 the root power sum equals the number of vertices.
