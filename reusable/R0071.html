/-- `godsil_pathTree_identity` gives a divisibility relation after deleting the starting vertex. -/
example {V : Type*} [Fintype V] [DecidableEq V] (G : SimpleGraph V) (u : V) :
    G.matchingPoly ∣ (G.induce {v | v ≠ u}).matchingPoly * (G.pathTree u).matchingPoly :=

  5. Fetch and check

    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Godsil’s path-tree identity: μ(G) μ(T−r) = μ(G−u) μ(T), where T is the path tree at u, r is its root, and deletion takes the induced graph on the remaining vertices.

Lean 4
theorem godsil_pathTree_identity {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) (u : V) :
    G.matchingPoly * ((G.pathTree u).induce {r | r ≠ G.pathTreeRoot u}).matchingPoly =
      (G.induce {v | v ≠ u}).matchingPoly * (G.pathTree u).matchingPoly

Lean docstring

Godsil's path-tree identity. Write T for the tree of simple paths starting at u and r for the trivial path. Then μ(G) μ(T - r) = μ(G - u) μ(T), where deleting a vertex takes the induced graph on the remaining vertices.

  • Archive: SimpleGraph.godsil_identity and SimpleGraph.matchingPoly_deleteIncidenceSet_isolate.
  • Classical reference: C. D. Godsil, Matchings and walks in graphs, J. Graph Theory 5 (1981) 285–297.
  • Example: the result gives the polynomial identity needed to compare the two deletion ratios.
