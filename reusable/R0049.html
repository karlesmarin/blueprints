Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Lean docstring

**The Dirichlet identity τ ∗ φ = σ.** For every n, Σ_{d ∣ n} τ(d) φ(n/d) = σ(n), where τ(d) is the number of divisors of d, φ Euler's totient and σ(n) the sum of the divisors of n.

  • Archive: DivisorTotient.sum_card_divisors_mul_totient (Formalizations.NumberTheory.ArithmeticFunction.DivisorTotient); the module cites no paper DOI of ours.
  • Classical reference: G. H. Hardy, E. M. Wright, An Introduction to the Theory of Numbers, Ch. XVI (the arithmetical functions φ, d and σ).
  • Example: for n = 6, τ(1)φ(6) + τ(2)φ(3) + τ(3)φ(2) + τ(6)φ(1) = 2 + 4 + 2 + 4 = 12 = σ(6).
