Reusable layer v0.2.0

20 results of the formalizations archive under stable names Formalizations.Reusable.*. Each is proved by the archive theorem it re-exposes (no proof is copied). Usage example: 20 of 20. Axioms audited, standard only: 20 of 20. API marks lemmas to import into other proofs; showcase, classical theorems to consult.

Install directly from GitHub (Reservoir indexing pending).

1 Create a project

Shell
lake +leanprover/lean4:v4.35.0 new myproject std.toml
cd myproject

Standard template, not math: the math template adds its own Mathlib requirement pinned to the Lean release tag, not to the Mathlib commit this package is built and tested with, so you would get a second, different Mathlib. Mathlib comes in through this package. Skip this step in an existing project with the same Lean and Mathlib.

2 Add to lakefile.toml

TOML
[[require]]
name = "formalizations"
git = "https://github.com/karlesmarin/formalizations"
rev = "v0.2.0"

3 Import one area

Lean 4
import Formalizations.Reusable.Geometry

or the whole layer: import Formalizations.Reusable. Each page gives the area and a compiled example.

4 Fetch and check

Shell
lake update
lake lean Example.lean

lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code.

Pappus's hexagon theorem in homogeneous coordinates over any commutative ring: if A, B, C are collinear and a, b, c are collinear, the meets Ab∩aB, Ac∩aC, Bc∩bC are collinear, with no non-degeneracy hypothesis.

Wolstenholme's inequality, defect form

If A + B + C = π, then x² + y² + z² − (2yz cos A + 2zx cos B + 2xy cos C) = (x − z cos B − y cos C)² + (z sin B − y sin C)² for all real x, y, z; hence Wolstenholme's inequality.
