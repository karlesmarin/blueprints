  have := matrix_rank_add_le A A
  omega

    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Subadditivity of the rank. Over a field K, for matrices A B : Matrix m n K, rank (A + B) ≤ rank A + rank B. Mathlib states this for linear maps (LinearMap.rank_add_le); this is the Matrix.rank form.

  • Archive: Matrix.rank_add_le (Formalizations.LinearAlgebra.Matrix.BlockRank, a shared lemma of the free-locus certificates of the same archive).
  • Classical reference: textbook (the image of A + B lies in the sum of the images).
  • Example: with B = −A, matrix_rank_add_le A (-A) gives rank 0 ≤ rank A + rank (−A).

Upstream

the Matrix.rank form of LinearMap.rank_add_le; a three-line lemma
