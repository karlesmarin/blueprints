/-- Jacobi's formula on the characteristic matrix: `charpoly′ = trace (adjugate (X − M))`. -/
example (M : Matrix (Fin 3) (Fin 3) ℚ) :
    Polynomial.derivative M.charpoly = M.charmatrix.adjugate.trace := by
  have h1 : M.charmatrix.map Polynomial.derivative = 1 := by
    ext i j
    by_cases h : i = j
    · subst h
      simp [charmatrix_apply_eq]
    · simp [charmatrix_apply_ne _ _ _ h, one_apply_ne h]
  rw [charpoly, derivative_det_eq_trace_adjugate_mul, h1, Matrix.mul_one]

Jacobi's formula: for a square matrix A of polynomials over a commutative ring, derivative (det A) = trace (adjugate A · A.map derivative).

theorem derivative_det_eq_trace_adjugate_mul {n R : Type*} [Fintype n] [DecidableEq n]
    [CommRing R] (A : Matrix n n (Polynomial R)) :
    Polynomial.derivative A.det = (A.adjugate * A.map Polynomial.derivative).trace

Lean docstring

Jacobi's formula. For a square matrix A with entries in R[X] (R a commutative ring), derivative (det A) = trace (adjugate A * A.map derivative). With A = X • 1 − M it gives charpoly′ = trace (adjugate (X − M)), the sum of the characteristic polynomials of the principal submatrices. Mathlib has only the special case derivative_det_one_add_X_smul (the first-order term of det (1 + X M)).

  • Archive: Matrix.derivative_det (Formalizations.LinearAlgebra.Matrix.Charpoly.Jacobi, a tool for the Ihara trace formula in the same archive); the module cites no paper DOI of ours.
  • Classical reference: C. G. J. Jacobi, De formatione et proprietatibus determinantium, J. Reine Angew. Math. 22 (1841); R. A. Horn, C. R. Johnson, Matrix Analysis, 2nd ed. (2013).
  • Example: for A = !![X, 1; 0, X] over ℚ, it gives derivative (X²) = 2 X.
