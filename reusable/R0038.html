Integer orthonormal columns are signed unit vectors

If an integer m × n matrix A satisfies AᵀA = I, every column j is \(±e_{f(j)}\) for an injective f : n → m (signed unit vectors in distinct rows); in particular an integer vector with v·v = 1 is ±e_i. False over ℚ.

Lean docstring

Integer orthonormal columns are signed unit vectors. If an integer m × n matrix satisfies Aᵀ A = 1, then every column j is ± Pi.single (f j) 1 for an injective f : n → m: the nonzero entries of distinct columns lie in distinct rows. The one-vector case (an integer vector with v ⬝ᵥ v = 1 is ± Pi.single i 1) is IntOrthonormal.eq_single_of_dotProduct_self_eq_one. False over ℚ: (3/5, 4/5) has norm one.

  • Archive: IntOrthonormal.columns_of_transpose_mul_self (Formalizations.LinearAlgebra.Matrix.IntOrthonormal; also IntOrthonormal.eq_single_of_dotProduct_self_eq_one); a piece of the design table (first step of the integer lengths of P_H, signed graphs).
  • Classical reference: textbook (sums of integer squares).
  • Example: the columns of !![0, 1; -1, 0] are -e₁ and e₀.

Upstream

Mathlib has signed permutation matrices but not this characterization of integer matrices with orthonormal columns
