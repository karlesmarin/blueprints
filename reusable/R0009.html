Over a field, the rank of the block upper-triangular matrix [[A, B], [0, D]] is at most the number of rows of A plus the rank of D.

Lean docstring

Rank of a block upper-triangular matrix. Over a field K, for blocks A : l × n, B : l × o and D : p × o, rank !![A, B; 0, D] ≤ |l| + rank D. The proof splits the block matrix as fromBlocks A B 0 0 + fromBlocks 0 0 0 D and uses subadditivity of the rank (also in the archive, Matrix.rank_add_le, which Mathlib states only for linear maps).

  • Archive: Matrix.rank_fromBlocks_zero₂₁_le_right (Formalizations.LinearAlgebra.Matrix.BlockRank, used by the free-locus certificates of the same archive).
  • Classical reference: a textbook consequence of the subadditivity of the rank (no single source).
  • Example: with A = 1 : Matrix (Fin 1) (Fin 1) ℚ, any B and D : Matrix (Fin 2) (Fin 2) ℚ, rank_fromBlocks_zero₂₁_le_card_add_rank A B D : (fromBlocks A B 0 D).rank ≤ 1 + D.rank.
