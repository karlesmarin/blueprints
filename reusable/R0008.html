Pomerance's theorem on the middle binomial coefficient

For every integer k ≥ 1, the set of n with n + k dividing the central binomial coefficient C(2n, n) has asymptotic density 1.

Lean docstring

Pomerance's theorem on the middle binomial coefficient (Theorem 2 of the paper). For every integer k ≥ 1, the set of n with n + k ∣ C(2n, n) has asymptotic density 1: #{n < x : n + k ∣ C(2n, n)} / x → 1 as x → ∞. (For k = 1 every n qualifies: C(2n, n)/(n+1) is the Catalan number.)

  • Archive: MiddleBinomial.tendsto_density_add_dvd_centralBinom (Formalizations.Combinatorics.Choose.MiddleBinomialDensity, with the counting of base-p digits ≥ p/2 for the primes p < 2k).
  • Paper formalized: C. Pomerance, Divisors of the middle binomial coefficient, Amer. Math. Monthly 122 (2015) 636–644, Theorem 2, doi:10.4169/amer.math.monthly.122.7.636.
  • Example: pomerance_density_add_dvd_centralBinom 2 (by norm_num): almost every n has n + 2 ∣ C(2n, n).
