Cotes' harmonic means theorem

Cotes' harmonic means theorem: if a line p + t v meets a real plane curve f = 0 in deg g real points (g(t) = f(p + t v) splits), the harmonic-mean point lies on the polar line ∇f(p)·(q − p) = −d f(p) of p.

theorem cotes_harmonic_mean_polar (f : MvPolynomial (Fin 2) ℝ) (p v : Fin 2 → ℝ)
    (hp : MvPolynomial.eval p f ≠ 0)
    (g : Polynomial ℝ)
    (hg : g = MvPolynomial.aeval (fun i => Polynomial.C (p i) + Polynomial.C (v i) * Polynomial.X) f)
    (hsplit : g.roots.card = g.natDegree) (hd : 1 ≤ g.natDegree)
    (hH : (g.roots.map (fun r => r⁻¹)).sum ≠ 0) :
    ∑ i, MvPolynomial.eval p (MvPolynomial.pderiv i f) *
        ((g.natDegree : ℝ) / (g.roots.map (fun r => r⁻¹)).sum * v i)
      = -(g.natDegree : ℝ) * MvPolynomial.eval p f

Lean docstring

Cotes' harmonic means theorem. Let f ∈ ℝ[x, y] define a plane curve, p a point with f(p) ≠ 0 and v a direction, and let g(t) = f(p + t v). Suppose g splits over ℝ with d = deg g ≥ 1 roots tᵢ and Σ 1/tᵢ ≠ 0. Then the harmonic-mean point p + t* v, t* = d / Σ 1/tᵢ, satisfies ∇f(p) · (t* v) = −d f(p): it lies on the polar line ∇f(p) · (q − p) = −d f(p) of p, which does not depend on the direction v.

  • Archive: Cotes.harmonic_mean_polar (Formalizations.AlgebraicGeometry.PlaneCurve.Cotes, from Mathlib's logarithmic derivative of a split polynomial); no research paper.
  • Classical reference: R. Cotes, Harmonia Mensurarum, Cambridge, 1722; C. Maclaurin, De linearum geometricarum proprietatibus generalibus, 1748.
  • Example: for the unit circle f = x² + y² − 1, p = 0 and any v, g = |v|² t² − 1 splits with Σ 1/tᵢ = 0, so the hypothesis hH fails: the theorem says nothing about lines through the centre, as expected (the polar of the centre is the line at infinity).

the hypotheses (roots.card = natDegree, nonzero sum of inverse roots) are tailored to the proof; a Mathlib version would need plane-curve API
