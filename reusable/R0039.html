/-- Generalised Hlawka for `n = 4` vectors of `ℝ`: `d₂ + d₃ ≤ 3 (d₁ + d₄)`. -/
example (x : Fin 4 → ℝ) :
    ∑ k ∈ Finset.Icc 2 (4 - 1), ∑ S ∈ (Finset.univ : Finset (Fin 4)).powersetCard k, ‖∑ i ∈ S, x i‖

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

theorem hlawka_generalised {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] {n : ℕ}

Lean docstring

Generalised Hlawka inequality (Djoković 1963; Smiley–Smiley 1964). For n ≥ 3 vectors of a real inner product space, write d_k for the sum of the norms of all k-element subsums. Then d_2 + ⋯ + d_{n-1} ≤ (2^(n-2) - 1) (d_1 + d_n). For n = 3 this is Hlawka's inequality ‖x+y‖ + ‖y+z‖ + ‖z+x‖ ≤ ‖x‖ + ‖y‖ + ‖z‖ + ‖x+y+z‖.

  • Archive: Hlawka.generalised (Formalizations.Analysis.InnerProductSpace.Hlawka; the case n = 3 is Hlawka.norm_add_add_le); the module cites no paper DOI of ours.
  • Classical reference: D. Ž. Djoković, Generalizations of Hlawka's inequality, Glasnik Mat.-Fiz. Astronom. 18 (1963) 169–175; D. M. Smiley, M. F. Smiley, The polygonal inequalities, Amer. Math. Monthly 71 (1964) 755–760.
  • Example: four vectors of ℝ, n = 4: d_2 + d_3 ≤ 3 (d_1 + d_4).
