    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Real-rootedness is stable under reversal. If a real polynomial p splits over ℝ, so does its reverse p.reverse = Xᵈᵉᵍ ᵖ · p(1/X) (Mathlib's Polynomial.reverse): the nonzero roots are inverted, and a vanishing constant term only lowers the degree. With splits_derivative, it reduces statements about the middle coefficients of a real-rooted polynomial to a real-rooted quadratic.

  • Archive: Newton.RealRooted.reverse (Formalizations.Analysis.Polynomial.RealRoots.NewtonInequalities), restated with Polynomial.Splits through realRooted_iff_splits; the module cites no paper DOI of ours.
  • Classical reference: the reversal step of the classical proof of Newton's inequalities; G. H. Hardy, J. E. Littlewood, G. Pólya, Inequalities, 2nd ed. (1952), ch. II.
  • Example: X · (X − 2) splits, so its reverse 1 − 2X splits.

Upstream

Mathlib has no Splits lemma for Polynomial.reverse; about thirty lines, and the statement holds over any field
