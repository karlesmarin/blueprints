  4. Paste the example

open scoped Kronecker

/-- A block upper-triangular matrix with identity diagonal blocks is invertible, whatever its
corner `B`: its rank is at least `2 + 2`. -/
example (B : Matrix (Fin 2) (Fin 2) ℚ) :
    4 ≤ (fromBlocks (1 : Matrix (Fin 2) (Fin 2) ℚ) B 0 (1 : Matrix (Fin 2) (Fin 2) ℚ)).rank := by
  have h := matrix_rank_add_rank_le_rank_fromBlocks (1 : Matrix (Fin 2) (Fin 2) ℚ) B
    (1 : Matrix (Fin 2) (Fin 2) ℚ)
  simpa only [rank_one, Fintype.card_fin] using h

  5. Fetch and check

    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Over a field, rank A + rank D ≤ rank of the block upper-triangular matrix fromBlocks A B 0 D.

Lean docstring

Lower bound for the rank of a block upper-triangular matrix. Over a field K, for blocks A : l × n, B : l × o and D : p × o, rank A + rank D ≤ rank !![A, B; 0, D]. Together with rank_fromBlocks_zero₂₁_le_card_add_rank it pins the rank of a block-triangular certificate between rank A + rank D and |l| + rank D; with A invertible both bounds agree.

  • Archive: Matrix.rank_add_rank_le_rank_fromBlocks_zero₂₁ (Formalizations.LinearAlgebra.Matrix.Rank, used by the free-locus certificates of the same archive); proved through the nullity bound for block triangular matrices.
  • Classical reference: textbook (e.g. G. Marsaglia, G. P. H. Styan, Equalities and inequalities for ranks of matrices, Linear and Multilinear Algebra 2 (1974) 269–292).
  • Example: with A = D = 1 : Matrix (Fin 2) (Fin 2) ℚ, any B gives 4 ≤ rank !![1, B; 0, 1], so the 4 × 4 block matrix is invertible.
