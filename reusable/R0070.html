example {V : Type*} [Fintype V] [DecidableEq V] (G : SimpleGraph V) [DecidableRel G.Adj]
    (hdeg : ∀ v, G.degree v ≤ 2) {x : ℝ} (hx : G.matchingPoly.IsRoot x) : |x| ≤ 2 := by
  simpa [show (2 : ℝ) - 1 = 1 by norm_num] using matchingPoly_root_bound G 2 (by decide) hdeg hx

  5. Fetch and check

    Shell

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Heilmann–Lieb: if every vertex degree is at most Δ ≥ 2, then every real root of the matching polynomial lies in [−2√(Δ−1), 2√(Δ−1)].

Lean statement

Lean 4
theorem matchingPoly_root_bound {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] (Δ : ℕ) (hΔ : 2 ≤ Δ)
    (hdeg : ∀ v, G.degree v ≤ Δ) {x : ℝ} (hx : G.matchingPoly.IsRoot x) :
    |x| ≤ 2 * Real.sqrt ((Δ : ℝ) - 1)

Lean docstring

Heilmann–Lieb root bound. For a finite simple graph with all degrees at most Δ ≥ 2, every real root of the matching polynomial has absolute value at most 2√(Δ − 1). The polynomial splits over ℝ by matchingPoly_splits.

  • Archive: SimpleGraph.matchingPoly_bounded.
  • Classical reference: O. J. Heilmann, E. H. Lieb, Theory of monomer-dimer systems, Comm. Math. Phys. 27 (1972) 190–232.
  • Example: if all degrees are at most two, all roots lie in [-2, 2].
