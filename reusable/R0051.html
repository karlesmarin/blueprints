  1. Create a project

    Shell
    lake +leanprover/lean4:v4.35.0 new myproject std.toml
cd myproject

    Standard template, not math: the math template adds its own Mathlib requirement pinned to the Lean release tag, not to the Mathlib commit this package is built and tested with, so you would get a second, different Mathlib. Mathlib comes in through this package. Skip this step in an existing project with the same Lean and Mathlib.

  2. Add the dependency to lakefile.toml

    TOML
    [[require]]
name = "formalizations"
git = "https://github.com/karlesmarin/formalizations"
rev = "v0.13.0"

  3. Import the minimal module

    Lean 4
    import Formalizations.Reusable.Analysis

    In a file of the project, e.g. Example.lean.

  4. Paste the example

    Lean 4
    open Formalizations.Reusable Real Set
open MeasureTheory ProbabilityTheory in

/-- Zieliński–Zych at `α = 1` (the Margolus–Levitin case): `0 ≤ x − π/2 + (π/2) cos x + sin x` for `x ≥ 0`. -/
example {x : ℝ} (hx : 0 ≤ x) : 0 ≤ x - π / 2 + π / 2 * Real.cos x + Real.sin x := by
  have h := zielinski_zych_inequality one_pos hx
  simpa using h

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableAnalysisExample.lean at v0.13.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

The Zieliński–Zych inequality. For every α > 0 and x ≥ 0, 0 ≤ x^α − π^α/2 + (π^α/2) cos x + α π^(α−1) sin x. It is the analytic core of the fractional-moment quantum speed limit π^α ≤ 2 M_α τ^α; α = 1 is the Margolus–Levitin case.

  • Archive: QSL.zz_inequality_all (Formalizations.Physics.QuantumMechanics.SpeedLimit.ZielinskiZych; the archive proves it for 0 < α ≤ 1 by a harmonic-mean bound and for α ≥ 1 by Bernoulli plus a split of tan); the module cites no paper DOI of ours.
  • Classical reference: the inequality is stated (without proof) in M. Zieliński, M. Zych, Phys. Rev. A 74, 034301 (2006), as cited in the archive module.
  • Example: α = 1, the inequality 0 ≤ x − π/2 + (π/2) cos x + sin x behind the Margolus–Levitin bound.
