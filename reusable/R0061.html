/-- A diagonal resolvent series for a two-by-two matrix over the integers. -/
example (M : Matrix (Fin 2) (Fin 2) ℤ) :
    (PowerSeries.mk fun k => (M ^ k) 0 0) * (M.charpolyRev : ℤ⟦X⟧) =

  5. Fetch and check

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

For a square matrix M over a commutative ring, the power series with coefficients (Mᵏ)ᵢᵢ times the reversed characteristic polynomial of M equals the reversed characteristic polynomial of the principal submatrix deleting i.

Lean 4
theorem resolventSeries_diag_mul_coe_charpolyRev {n R : Type*} [Fintype n] [DecidableEq n]
    [CommRing R] (M : Matrix n n R) (i : n) :
    (PowerSeries.mk fun k => (M ^ k) i i) * (M.charpolyRev : R⟦X⟧) =
      ((M.submatrix (Subtype.val : {j // j ≠ i} → n) (Subtype.val : {j // j ≠ i} → n)).charpolyRev :
        R⟦X⟧)
