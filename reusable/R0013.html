  4. Paste the example

    Lean 4
    open Formalizations.Reusable Polynomial

/-- Sturm: if the Sturm chain of a squarefree `p` does not lose sign variations from `a` to `b`,
then `p` has no root in `(a, b]`. -/
example (p : Polynomial ℝ) (hp : Squarefree p) {a b : ℝ} (hab : a < b) (ha : p.eval a ≠ 0)
    (hb : p.eval b ≠ 0)
    (h : ((sturmSeq p (derivative p)).map (fun q => q.eval a)).signVariations ≤
      ((sturmSeq p (derivative p)).map (fun q => q.eval b)).signVariations) :
    ∀ x ∈ Set.Ioc a b, ¬ p.IsRoot x := by
  intro x hx hroot
  have hcount := sturm_signVariations_sub_eq_card_roots p hp hab ha hb
  have hmem : x ∈ p.roots.toFinset.filter (fun x => a < x ∧ x ≤ b) := by
    rw [Finset.mem_filter, Multiset.mem_toFinset, mem_roots hp.ne_zero]
    exact ⟨hroot, hx.1, hx.2⟩
  have hpos := Finset.card_pos.2 ⟨x, hmem⟩
  omega

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusablePolynomialExample.lean at v0.2.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Sturm's theorem. For a squarefree real polynomial p and a < b with p a ≠ 0 and p b ≠ 0, the number of sign variations of Mathlib's Sturm chain Polynomial.sturmSeq p (derivative p) evaluated at a, minus the number at b, is the number of distinct real roots of p in (a, b]. Sign variations are Mathlib's List.signVariations (zeros are skipped).

  • Archive: Sturm.sturm (Formalizations.Analysis.Polynomial.RealRoots.Sturm), restated with Mathlib's chain and counter through the archive bridges Sturm.sturmSeq_eq and Sturm.signVarAt_eq_signVariations. Mathlib's Polynomial.sturmSeq contains only the algebraic properties of the chain; this is the theorem it is defined for.
  • Classical reference: C. Sturm (1829); S. Basu, R. Pollack, M.-F. Roy, Algorithms in Real Algebraic Geometry, ch. 2.
  • Example: for p = X² − 2 on [0, 2], the theorem counts the single root √2.
