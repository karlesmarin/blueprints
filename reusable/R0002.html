  4. Paste the example

    Lean 4
    open Formalizations.Reusable Matrix Real

/-- Wolstenholme's inequality, from the defect identity. -/
example (x y z A B C : ℝ) (h : A + B + C = π) :
    2 * y * z * Real.cos A + 2 * z * x * Real.cos B + 2 * x * y * Real.cos C
      ≤ x ^ 2 + y ^ 2 + z ^ 2 := by
  have := wolstenholme_defect_eq_sq_add_sq x y z A B C h
  nlinarith [sq_nonneg (x - z * Real.cos B - y * Real.cos C),
    sq_nonneg (z * Real.sin B - y * Real.sin C)]

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableGeometryExample.lean at v0.2.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

Wolstenholme's inequality, defect form. If A + B + C = π then for all real x, y, z, x² + y² + z² − (2yz cos A + 2zx cos B + 2xy cos C) = (x − z cos B − y cos C)² + (z sin B − y sin C)². In particular 2yz cos A + 2zx cos B + 2xy cos C ≤ x² + y² + z² (Wolstenholme's inequality, archive WolstenholmeInequality.cos_le). No sign condition on the angles is needed.

  • Archive: WolstenholmeInequality.sub_eq_sq_add_sq (Formalizations.Geometry.Euclidean.WolstenholmeInequality); no research paper.
  • Classical reference: J. Wolstenholme, A Book of Mathematical Problems, Macmillan, 1867.
  • Example: wolstenholme_defect_eq_sq_add_sq 1 1 1 (π/3) (π/3) (π/3) h for the equilateral triangle, with h : π/3 + π/3 + π/3 = π.
