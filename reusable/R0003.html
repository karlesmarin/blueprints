  4. Paste the example

    volume {q : (ℝ × ℝ) × ℝ | 1 ≤ q.2 ∧ Real.sqrt (q.1.1 ^ 2 + q.1.2 ^ 2) ≤ 1 / q.2} ≠ ⊤ := by
  rw [torricelli_trumpet.1]
  exact ENNReal.ofReal_ne_top

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableMeasureTheoryExample.lean at v0.1.1, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

        = ENNReal.ofReal Real.pi ∧
      volume {p : ℝ × ℝ | 1 ≤ p.1 ∧ |p.2| ≤ 1 / p.1} = ⊤

Lean docstring

Torricelli's trumpet (Gabriel's horn). The solid {(u, v, t) : t ≥ 1, √(u² + v²) ≤ 1/t} in ℝ³ (the revolution of y = 1/x, x ≥ 1, about the axis) has Lebesgue volume π, while its plane section {(x, y) : x ≥ 1, |y| ≤ 1/x} has infinite area. (The archive also proves that the surface integrand is not integrable, i.e. the infinite surface area.)

  • Archive: Torricelli.volume_trumpet and Torricelli.volume_section_eq_top (Formalizations.MeasureTheory.Torricelli, on the archive's Pappus–Guldin volume_revolution); no research paper.
  • Classical reference: E. Torricelli, Opera geometrica (1644); P. Mancosu, Philosophy of Mathematics and Mathematical Practice in the Seventeenth Century, OUP 1999, ch. 5.
  • Example: torricelli_trumpet.1 is the volume π; torricelli_trumpet.2 the infinite area.
