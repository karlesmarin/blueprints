  4. Paste the example

    Lean 4
    open Formalizations.Reusable

/-- Doubling sends some point of the cyclic interval `{0, 1}` modulo 5 outside the interval. -/
example : ∃ x : ZMod 5, x.val < 2 ∧ 2 ≤ ((2 : ZMod 5) * x).val := by
  let a : (ZMod 5)ˣ := ⟨2, 3, by decide, by decide⟩
  have h := amiot_interval (n := 5) (k := 2) (by decide) (by decide) 0 a (by decide) (by decide)
  push Not at h
  simpa [a] using h

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableNumberTheoryExample.lean at v0.14.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

A cyclic interval of k consecutive residues modulo n, with 1 < k < n − 1, cannot be preserved by multiplication by a unit other than ±1.

Lean statement

Lean 4
theorem amiot_interval {n k : ℕ} (hk1 : 1 < k) (hk2 : k < n - 1) (c₀ : ZMod n)
    (a : (ZMod n)ˣ) (ha1 : (a : ZMod n) ≠ 1) (ha2 : (a : ZMod n) ≠ -1) :
    ¬ ∀ x : ZMod n, (x - c₀).val < k → ((a : ZMod n) * x - c₀).val < k

Lean docstring

Amiot's interval lemma. For 1 < k < n − 1, some point of the cyclic interval of length k starting at c₀ leaves the interval when multiplied by any specified unit a ≠ ±1. Membership in this interval is expressed by (x - c₀).val < k.
