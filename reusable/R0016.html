  4. Paste the example

    open Formalizations.Reusable Real Set

/-- Eneström–Kakeya: `1 + z/2 + z²/3` (coefficients `1 ≥ 1/2 ≥ 1/3 > 0`) has no zero in the open
unit disc. -/
example {z : ℂ} (hz : ‖z‖ < 1) : (1 : ℂ) + z / 2 + z ^ 2 / 3 ≠ 0 := by
  have h := enestrom_kakeya_ne_zero (n := 2) (fun k => 1 / ((k : ℝ) + 1))
    (fun k _ => by positivity)
    (fun k _ => one_div_le_one_div_of_le (by positivity) (by push_cast; linarith)) hz
  convert h using 1
  simp only [Finset.sum_range_succ, Finset.sum_range_zero]
  push_cast
  ring

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableAnalysisExample.lean at v0.2.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Lean docstring

The Eneström–Kakeya theorem. A polynomial ∑_{k=0}^n a_k z^k with real coefficients a_0 ≥ a_1 ≥ ⋯ ≥ a_n > 0 has no zero in the open unit disc ‖z‖ < 1. The proof multiplies by 1 − z, telescopes and applies the triangle inequality. (In the other common form, increasing positive coefficients give no zero outside the closed unit disc; it follows by reversing the polynomial.)

  • Archive: Dilog.enestrom_kakeya (Formalizations.Analysis.Polynomial.EnestromKakeya, in the namespace of the dilogarithm notes of the same archive; the module also has the boundary case, Dilog.enestrom_kakeya_boundary).
  • Classical reference: G. Eneström (1893), S. Kakeya, Tôhoku Math. J. 2 (1912); Q. I. Rahman, G. Schmeisser, Analytic Theory of Polynomials (2002).
  • Example: 1 + z/2 + z²/3 (coefficients 1 ≥ 1/2 ≥ 1/3 > 0) has no zero with ‖z‖ < 1.
