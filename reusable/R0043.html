  4. Paste the example

    Lean 4
    open Formalizations.Reusable Filter Topology

/-- Bruck–Ryser–Chowla: no finite projective plane has order `6` (`6 ≡ 2 mod 4`, `6` is not a sum of two
squares). -/
example (P L : Type*) [Membership P L] [Configuration.ProjectivePlane P L] [Finite P] [Finite L] :
    Configuration.ProjectivePlane.order P L ≠ 6 := by
  intro h6
  obtain ⟨a, b, hab⟩ := bruck_ryser_chowla P L (Or.inr (by rw [h6]))
  rw [h6] at hab
  have ha : a ≤ 2 := by nlinarith
  have hb : b ≤ 2 := by nlinarith
  interval_cases a <;> interval_cases b <;> omega

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableCombinatoricsExample.lean at v0.8.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Bruck–Ryser–Chowla: if a finite projective plane of order n exists and n ≡ 1 or 2 (mod 4), then n is a sum of two squares (so no plane of order 6 or 14).

Lean 4
theorem bruck_ryser_chowla (P L : Type*) [Membership P L] [Configuration.ProjectivePlane P L] [Finite P]
    [Finite L]
    (h : Configuration.ProjectivePlane.order P L % 4 = 1 ∨
      Configuration.ProjectivePlane.order P L % 4 = 2) :
    ∃ a b : ℕ, Configuration.ProjectivePlane.order P L = a ^ 2 + b ^ 2

Bruck–Ryser–Chowla theorem. If a finite projective plane of order n exists and n ≡ 1 or 2 (mod 4), then n is a sum of two squares (so there is no plane of order 6 or 14).
