example (A : Matrix (Fin 3) (Fin 2) ℚ) (B : Matrix (Fin 2) (Fin 3) ℚ) : (A * B).det = 0 := by

Cauchy–Binet: for A : m × n and B : n × m over a commutative ring (n linearly ordered), det (A B) is the sum over the |m|-subsets S of n of det A[:, S] · det B[S, :].

Lean statement

Lean 4
theorem det_mul_eq_sum_det_submatrix_mul_det_submatrix {R m n : Type*} [CommRing R] [Fintype m]
    [DecidableEq m] [Fintype n] [LinearOrder n] (A : Matrix m n R) (B : Matrix n m R) :
    (A * B).det =
      ∑ S : {s : Finset n // s.card = Fintype.card m},
        (A.submatrix (Fintype.equivFin m).symm (S.1.orderEmbOfFin S.2)).det *
        (B.submatrix (S.1.orderEmbOfFin S.2) (Fintype.equivFin m).symm).det

Lean docstring

The Cauchy–Binet formula. Over a commutative ring R, for A : Matrix m n R and B : Matrix n m R with n linearly ordered, det (A * B) is the sum, over the subsets S of n with |S| = |m|, of det A[:, S] · det B[S, :], the columns of A and the rows of B taken in the increasing order of S (S.orderEmbOfFin) and the rows of A, columns of B through Fintype.equivFin m. When |n| < |m| the sum is empty and det (A * B) = 0.

  • Archive: Matrix.det_mul_cauchyBinet (Formalizations.LinearAlgebra.Matrix.CauchyBinet, the tool for Kirchhoff's matrix-tree theorem in the same archive); the module cites no paper DOI of ours.
  • Classical reference: A.-L. Cauchy (1815), J. Binet (1815); F. R. Gantmacher, The Theory of Matrices, vol. 1.
  • Example: for A : Matrix (Fin 1) (Fin 2) ℚ, B : Matrix (Fin 2) (Fin 1) ℚ it gives det (A * B) = A 0 0 * B 0 0 + A 0 1 * B 1 0, a sum of two 1 × 1 minors.
