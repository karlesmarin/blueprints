  1. Create a project

    Shell
    lake +leanprover/lean4:v4.35.0 new myproject std.toml

    Standard template, not math: the math template adds its own Mathlib requirement pinned to the Lean release tag, not to the Mathlib commit this package is built and tested with, so you would get a second, different Mathlib. Mathlib comes in through this package. Skip this step in an existing project with the same Lean and Mathlib.

  2. Add the dependency to lakefile.toml

    TOML

  3. Import the minimal module

    Lean 4
    import Formalizations.Reusable.NumberTheory

    In a file of the project, e.g. Example.lean.

  4. Paste the example

    Lean 4
    open Formalizations.Reusable

/-- Dedekind reciprocity at `h = k = 1`: `s(1, 1) + s(1, 1) = 0`. -/
example : DedekindSum.ded 1 1 + DedekindSum.ded 1 1 = 0 := by
  have h := ded_reciprocity (h := 1) (k := 1) (by norm_num) one_pos one_pos
  norm_num at h
  rw [h]; norm_num

    Steps 3 and 4 together are a complete Lean file:FormalizationsTest/ReusableNumberTheoryExample.lean at v0.8.0, compiled by the CI.

  5. Fetch and check

    Shell
    lake update
lake lean Example.lean

    lake update fetches this package and Mathlib, and Mathlib's update hook downloads the compiled Mathlib (lake exe cache get). lake lean Example.lean builds the imports of the file (steps 3 and 4) and checks it. If the file belongs to a lean_lib of your project, lake build <lib> does the same. Avoid a bare lake build in a project from the standard template: its default target is the executable, whose link compiles every imported Mathlib module to native code. Same versions required: Lean v4.35.0, Mathlib f0b4c81.

Alternative: import Formalizations.Reusable imports the whole layer (all areas).

Dedekind reciprocity: for coprime positive integers h, k, s(h,k) + s(k,h) = (h² + k² + 1)/(12hk) − 1/4, with s(h,k) = \(Σ_{r<k}\) ((r/k))((hr/k)) the Dedekind sum.

Lean statement

Lean 4
theorem ded_reciprocity {h k : ℕ} (hc : Nat.Coprime h k) (hh : 0 < h) (hk : 0 < k) :
    DedekindSum.ded h k + DedekindSum.ded k h = ((h : ℚ) ^ 2 + k ^ 2 + 1) / (12 * h * k) - 1 / 4

Lean docstring

Dedekind reciprocity. For coprime positive integers h, k, the Dedekind sums s(h, k) = Σ_{r<k} ((r/k)) ((hr/k)), with the sawtooth ((x)) = x - ⌊x⌋ - 1/2 (and 0 at integers), satisfy s(h, k) + s(k, h) = (h² + k² + 1) / (12 h k) − 1/4.

  • Archive: DedekindSum.ded_reciprocity (Formalizations.NumberTheory.DedekindSum, with the definitions DedekindSum.saw and DedekindSum.ded); the module cites no paper DOI of ours.
  • Classical reference: R. Dedekind, in B. Riemann, Gesammelte mathematische Werke (2nd ed., 1892), 466–478; H. Rademacher, E. Grosswald, Dedekind Sums, Carus Math. Monogr. 16 (1972).
  • Example: s(1, 1) + s(1, 1) = 0.

Upstream
