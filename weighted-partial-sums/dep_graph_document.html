Corollary 13how many components vanish, and which

Let \(f\ge 5\) be prime, let \(t\) be the order of \(2\) in \(({\mathbb {Z}}/f)^\times \) and \(d=\varphi (f)/2\). On the diagonal \(m=(f-1)/2\) the components that vanish are exactly those at the odd characters trivial on \(\langle 2\rangle \), so their number is

\[ { \boxed {\displaystyle \# \{ \chi \ \text{odd}:\ T(m,\chi )=0\} = \begin{cases} 0,& -1\in \langle 2\rangle ,\\[2pt] d/t,& -1\notin \langle 2\rangle .\end{cases}}} \]

Corollary 8zeros from digits

Let \(R_q=\{ 0\le r{\lt}q:\ T_q+q\, C(r)=0=T(r)\} \). Every \(m\ge 1\) whose base-\(q\) digits all lie in \(R_q\) has \(S_\chi (m)=0\), for both values of \(s\).

  1. If \(q\equiv 1\pmod4\), then \(0,q-1\in R_q\), and \(S_\chi \) has at least \(2^J-1\) zeros below \(q^J\), hence at least \(\tfrac 12X^{\log 2/\log q}-1\) below \(X\).

  2. If \(q\equiv 7\pmod8\), then \((q-1)/2\in R_q\), and \({ \boxed {\displaystyle S_\chi \bigl(\tfrac {q^j-1}{2}\bigr)=0}}\) for every \(j\ge 1\).

  3. If \(q\equiv 3\pmod4\), \(q{\gt}3\), \(h(-q)=1\) and \(s=1\), then \(S_\chi (z)=0\) along \(z_0=q\), \(z_{i+1}=q(z_i+1)\). For \(q=3\) and \(s=1\) the same holds with \(27\) in place of \(q\): \(z_0=27\), \(z_{i+1}=27(z_i+1)\).

  4. For every \(q\) and \(s\): if \(S_\chi (qk)=0\) and \(C(r)=T(r)=0\), then \(S_\chi (qk+r)=0\). When \(\chi (2)=\chi (3)=-1\) this applies with \(r=4\), since \(1-2-3+4=0\).

  5. If \(s=-1\), then \(S_\chi (q^2m)=q^2S_\chi (m)\) for every \(m\): a single zero of \(S_\chi \) gives infinitely many.

Corollary 17the rows

Let \(n=2m+1\). The row \(m\) contains an odd quadratic character \(\chi \) of prime conductor \(f{\gt}n\) with \(T(m,\chi )=0\) if and only if \(\bigl(\frac2n\bigr)=1\), and then it contains infinitely many.

Corollary 10every order

Let \(q\) be an odd prime, \(\chi \) an odd Dirichlet character modulo \(q\) of any order, extended completely multiplicatively by any root of unity \(\chi (q)\), and \(S_\chi (m)=\sum _{n\le m}n\chi (n)\). Then \(S_\chi \bigl(\tfrac {q-1}2\bigr)=0\) if and only if \(\chi (2)=1\), and in that case \(S_\chi \bigl(\tfrac {q^j-1}2\bigr)=0\) for every \(j\ge 1\). The characters for which this happens are the odd characters trivial on \(\langle 2\rangle \); Corollary 13 counts them.

Lemma 12the components

Let \(f\) be prime. Then \(\widehat S(\chi )=\bigl(1-\chi (-1)\bigr)T(m,\chi )\), which is \(2T(m,\chi )\) for \(\chi \) odd and \(0\) for \(\chi \) even, and

\[ { \boxed {\displaystyle \operatorname {rank}_{{\mathbb {Q}}}\mathcal M=\# \{ \chi \ \text{odd}:\ T(m,\chi )\neq 0\} .}} \]

In particular \(\mathcal M\) has rank below \((f-1)/2\) over \({\mathbb {Q}}\) exactly when some odd character has \(T(m,\chi )=0\), and its defect counts those characters.

Lemma 3intervals of subset sums

Write \(\Sigma (A)\) for the set of subset sums of a finite set \(A\) of positive integers.

  1. If \(\Sigma (A)\supseteq [\alpha ,\beta ]\) and \(x\notin A\), \(0{\lt}x\le \beta -\alpha +1\), then \(\Sigma (A\cup \{ x\} )\supseteq [\alpha ,\beta +x]\). As \(\Sigma (A)\) is symmetric under \(x\mapsto P_A-x\), \(\Sigma (A)\supseteq [\alpha ,\beta ]\) with \(\beta \ge P_A/2\) implies \(\Sigma (A)\supseteq [\alpha ,P_A-\alpha ]\).

  2. (pairs) Let \(q_0,u_1,v_1,\dots ,u_t,v_t\) be distinct odd integers, \(d_j=(v_j-u_j)/2\) with \(1\le d_j\le 1+d_1+\dots +d_{j-1}\), \(H=\sum d_j\), \(U=\sum u_j\), and \(q_0\le 2H+1\). Then \(\Sigma (\{ q_0,u_j,v_j\} )\supseteq [U+q_0-1,\ U+2H+1]\).

  3. (Sárközy, with Lev’s constants [ 26 , Thm. 4.23 ] ) If \(X\) is a set of \(n\) positive integers with maximum \(x^*\) and \(4x^*\le \ell \le n^2/(12\log (4x^*/n))\), then \(\Sigma (X)\) contains an arithmetic progression of \(\ell \) terms and step \(s\le 4x^*/n\), each term a sum of at most \(6\ell /n\) distinct elements of \(X\).

Proposition 18higher order off the diagonal

Let \(f\) be prime, \(\chi \) an odd character modulo \(f\) of order \(r{\gt}2\), and \(1\le m{\lt}(f-1)/2\).

  1. If \(\chi \) takes only the values \(\pm 1\) on \(1,\dots ,m\), then \(T(m,\chi )=0\) exactly when the sign pattern \(\varepsilon =\chi |_{[1,m]}\) solves the row \(m\), that is \(\sum _{c\le m}c\, \varepsilon (c)=0\).

  2. If \(r=4\), then \(\chi ^2\) is the Legendre symbol, \(\chi \) takes values \(\pm 1\) on the quadratic residues and \(\pm i\) on the non-residues, and \(T(m,\chi )=0\) exactly when the two signed sums, over the residues \(c\le m\) and over the non-residues \(c\le m\), vanish separately. In particular both \(\sum _{c\le m,\, (c|f)=1}c\) and \(\sum _{c\le m,\, (c|f)=-1}c\) must be even.

Remark 19the order \(2\) is critical

For \(f(p)\) independent and uniform in \(\mu _r\), extended completely multiplicatively, \(\mathbb E\, f(n)\overline{f(k)}=1\) exactly when \(n/k\) is an \(r\)-th power of a rational, and writing \(n=da^r\), \(k=db^r\) with \(\gcd (a,b)=1\),

\[ \mathbb E\Bigl|\sum _{n\le m}nf(n)\Bigr|^2=\sum _{\gcd (a,b)=1}a^rb^r\sum _{d\le m/\max (a,b)^r}d^2, \]

which is \(\sim C_rm^3\) for \(r\ge 3\) but of order \(m^3\log m\) for \(r=2\). The logarithm in Lemma 2 is a feature of real signs. Measured: The identity against the exact average over all \(r^{\pi (m)}\) assignments, \(r=2,3,4\), \(m\le 20\); \(C_4=0.3402817\ldots \) by the series and by the limit at \(m=10^{10}\).

Theorem 7the weighted half sum

Let \(f\) be odd and let \(\chi \) be an odd Dirichlet character modulo \(f\). Then

\[ { \boxed {\displaystyle \sum _{c=1}^{(f-1)/2}c\, \chi (c)\; =\; \frac f2\, B_{1,\chi }\, \bigl(\chi (2)^{-1}-1\bigr).}} \]

If moreover \(\chi \) is primitive, so that \(B_{1,\chi }\neq 0\), the sum vanishes if and only if \(\chi (2)=1\).

Theorem 14the rank on the diagonal; Jager–Lenstra, Girstmair

Let \(f\ge 3\) be odd, \(m=(f-1)/2\), and let \(\mathcal M=[\, S(u^{-1}c)\, ]\) be the moment matrix of the full period, with rows \(u\in G=({\mathbb {Z}}/f)^\times \) and a column for every class \(c\in {\mathbb {Z}}/f\). Then

\[ { \boxed {\displaystyle d-\operatorname {rank}_{{\mathbb {Q}}}\mathcal M=\# \{ \chi \ \text{odd}:\ \chi (2)=1\} = \begin{cases} 0,& -1\in \langle 2\rangle ,\\[2pt] d/t,& -1\notin \langle 2\rangle ,\end{cases}}} \]

with \(d=\varphi (f)/2\) and \(t\) the order of \(2\) modulo \(f\).
