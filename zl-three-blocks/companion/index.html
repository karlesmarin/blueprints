← Blueprint · 📦 Programs and data of «Why three blocks? The limited augmented Zarankiewicz number in fixed width»

Every number of the paper traces to a file here: the witnesses and tables, the rational dual certificates with their independent checkers, the exhaustive searches, and the complete outputs of the checks (outputs/). Indices start at 1, as in the paper.

FileWhat it computes or checks
zl.pyAdmissibility checker of Definition 2.1 (both readings of (C3)); exact small values as controls.
comprobar_literal_def.pySecond, independent admissibility checker: Definition 2.1 read literally, cell by cell.
zl_cert_sombras.pyProposition 6.1: rational dual certificates for every orbit of shadows (n <= 6).
cert_sombras_check.pyIndependent checker of the shadow certificates (standard library + Fraction).
zl_sombras_mip.pyTheorem B, n = 7: the shadow as 0/1 variables in one mixed integer program (floating point, evidence only).
zl_cert_canonica.pyTheorem D, n <= 6: rational dual certificates for the canonical base (anchor column fixed).
cert_canonica_check.pyIndependent checker of the canonical certificates.
zl_perfiles.pyTheorem E and Appendix A: the exact profile system (types, ports, permitted pairs), one LP per profile.
zl_perfiles_dual.sageTheorem E: exact rational duals of the profile LPs (Sage, PPL backend).
cert_perfiles_check.pyIndependent checker of the 29 profile certificates: rebuilds types, ports and permitted pairs from scratch.
f4_familias_check.pyTheorem E, lower bound: the two periodic families (data/F4_families.json) checked by both checkers, profile per residue.
zl_rho_realiza.pyTheorem C: realization of an optimal shadow program as an actual configuration (also --canonica for Theorem D).
zl_rho_exacto.sageTheorems C and D, n <= 5: the slopes by exact linear programming in Sage.
modulos_lambda.pyTheorem B, lower bound: the three-block modules for n = 3..12, checked by both checkers.
zl_tipos.pySection 7: F_n(m) exactly by the integer program over row types (CP-SAT).
tres_bloques_dual_check.pyProposition 6.3: weights, row budgets, modules and the maximum lambda_n in exact arithmetic, every partition with n <= 60.
tres_bloques_identidades.pyProposition 6.3: the two deficit identities, symbolically (SymPy).
cruce_escalera_m3.pySection 5: the three-column ladder 1/2, 2/3, 1 against the published formulas.
zl_nauty.pySection 7: maximum bases up to isomorphism (nauty) and the largest family for each (CP-SAT).
zl_e2_sim.pyHelper of zl_nauty.py: the family search with and without symmetry breaking.
zl_km.pyHelper of zl_nauty.py: maximum bases and their automorphisms.
zl_cpsat.pySection 7: z(m, n) and the largest family by constraint programming.
zl_cpsat_dlex.pySection 7: the same with double-lex symmetry breaking (second, independent run).
tensor_busqueda.pySection 8: exhaustive search over the maximum box-free bases of 3 x 3 x p, p <= 5, and their largest admissible families.
