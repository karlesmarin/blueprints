# Blueprints

What each paper proves, how its results depend on each other, and what exactly has been checked.

This repository holds the **published** companion sites (blueprints) of Carles Marín's papers and the library page
that indexes them, as static files. It is generated: do not edit it by hand.

- Library: `index.html`
- One folder per paper: its blueprint, for the published version named on its card
- `lean/`: the source of the formalizations (from the public repository karlesmarin/formalizations), shown in the
  library's panel
